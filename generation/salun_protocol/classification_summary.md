Metrics are D_f (forget accuracy = 100 − UA), D_r (retain accuracy), Test accuracy and confidence-based SVC MIA; smaller absolute gaps to Retrain are preferred. This uses an explicit coarse search within the published ranges, not an exact reproduction of unpublished grid choices.
